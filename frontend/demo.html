Gavilan College Library

This is a mock host page (a stand-in for the library's real site) used to develop and demo the embeddable chat widget. The page's own CSS is intentionally hostile to prove the widget's Shadow DOM isolation holds.

Try the widget

Click “Ask the Library” at the bottom-right. Then try:

  • “What are the library hours?” (answer + a source link)
  • “How do I check out a book?” (answer + a source link)
  • “I need a textbook for my class” (clarifying question, no sources)
  • “Can you help me find research articles?” (routes to a librarian)
  • Type trigger error to see the error + retry state.

Going live later

On this page the widget runs against a dev-only mock (mock.js) that intercepts its network call. To point it at the real backend, set the API Gateway /query URL in one place — the data-api-url attribute on the widget.js script tag — and drop mock.js. Nothing else changes.
