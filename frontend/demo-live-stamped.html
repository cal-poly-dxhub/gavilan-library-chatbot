Gavilan College Library

LIVE MODE — this page calls the REAL deployed backend. There is no mock here. Every question triggers a real POST /query to the API Gateway endpoint stamped into the widget tag (data-api-url), which runs live retrieval over the scraped library content and Bedrock generation. Responses cost real Bedrock calls and a cold first query can take ~15–25s while OpenSearch wakes.

This is a mock host page (a stand-in for the library's real site) used to test the embeddable chat widget against the live bot. The page's own CSS is intentionally hostile to prove the widget's Shadow DOM isolation holds.

Try the widget (real answers from scraped content)

Click “Ask the Library” at the bottom-right, then try questions that exercise the actual scraped library pages:

  • “What are the library hours?”
  • “Can I check out a laptop?”
  • “What research databases does the library have?”
  • “How do I get a library card?”

Answers should cite a source link back to a gavilan.edu/library page. If the widget shows an error, see the CORS note in the file header.

Pointing at a (re)deploy

The endpoint lives in ONE place: the data-api-url attribute on the widget.js script tag below, stamped in place of the https://98epl0bry3.execute-api.us-west-2.amazonaws.com/query token. Paste the ChatbotApiUrl value from the CDK outputs there as-is (it already ends in /query). No mock.js is loaded on this page.
